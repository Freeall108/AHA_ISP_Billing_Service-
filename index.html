সম্পূর্ণ Backup

সব speedybill_* LocalStorage data, profile, clients, invoices/payment state, packages, settings, language/theme এবং ভবিষ্যতে যোগ হওয়া app data একসাথে থাকবে। SHA-256 checksum-ও থাকবে।

Clients Only Backup & Restore

শুধুমাত্র বর্তমান Clients তালিকার ডাটা Backup/Restore হবে। Invoice, Payment, Packages, Settings, Admin/Staff Account বা অন্য কোনো app data এতে পরিবর্তন হবে না।

সম্পূর্ণ Restore

Restore করার আগে বর্তমান অবস্থার একটি Safety Snapshot রাখা হবে। Backup checksum/format যাচাই করে তারপর data replace হবে।

All Clear — নতুন করে সেটআপ

Admin Account-এ এটি চালু করলে Admin Profile রেখে সব App Data পরিষ্কার হবে। Staff Account-এ চালু করলে শুধু ওই Staff-এর নিজস্ব Clients, Packages, Website, Settings ও অন্যান্য Staff Data পরিষ্কার হবে; Staff ও Admin Account থাকবে। কাজটির আগে Safety Snapshot তৈরি হবে।

Google Drive-এ সহজে Backup Save

কোনো Client ID, OAuth setup বা Google password লাগবে না। Backup তৈরি করে ফোনের Share panel খুলবে—সেখান থেকে Google Drive নির্বাচন করলেই Drive-এ Save হবে।

সবচেয়ে নির্ভরযোগ্য পদ্ধতি: Backup তৈরি করুন → Download হবে → Google Drive খুলবে → + → Upload → Downloads থেকে Backup ফাইল নির্বাচন করুন।
নোট: Google OAuth ছাড়া কোনো HTML ওয়েব অ্যাপ সরাসরি আপনার Drive-এ ফাইল লিখতে পারে না।

Google Drive Cloud Backup

OAuth 2.0 দিয়ে আপনার নিজের Google Drive-এ Backup upload/restore হবে। Password বা Google account credential এই অ্যাপে সংরক্ষণ করা হবে না।

OAuth 2.0
প্রথমবার সেটআপ: Google Cloud Console-এ Drive API চালু করে একটি OAuth Web Client ID তৈরি করুন এবং সেটি উপরের Client ID ঘরে দিন। এই HTML ফাইলটি যেই domain/localhost থেকে চালাবেন সেটি OAuth Authorized JavaScript Origin-এ যোগ করতে হবে।
